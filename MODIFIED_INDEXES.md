# Modified indexes

Every one of the 256 glyph indexes, what Betaflight uses it for, and what Army Jay draws there.

Generated by `tools/gen_modified_indexes.py` from `armyjay_full.mcm`. Do not edit by hand -- `tools/validate.py` check 8 reads the coverage table below and fails the build if it disagrees with the real diff against stock.

**248 of 256 indexes differ from stock.** The 8 that do not are listed too, with their reason.

## Index allocation

This is the table section 5 of the handoff asks for: proof that the boot splash range and the in-flight logo range do not conflict.

| Range | Count | Purpose |
|---|---|---|
| `0x00` | 1 | `SYM_NONE`. Protected: blanks the screen on video init. |
| `0x01`-`0x1F` | 31 | Status and unit icons, heading tape, stick overlay, satellites. |
| `0x20`-`0x5F` | 64 | ASCII: space, punctuation, digits, capitals. Meanings preserved. |
| `0x60`-`0x6F` | 16 | Home direction arrows, 16 headings. |
| `0x70`-`0x9F` | 48 | Crosshair, AH ladder, progress bar, battery states, unit labels. |
| `0xA0`-`0xFE` | 95 | Boot splash tiles (24 wide x 4 rows from `SYM_LOGO_START`). |
| `0xBF`-`0xC8` | 10 | In-flight wordmark. **Nested inside the splash range**, not additional to it. |
| `0xFF` | 1 | `SYM_END_OF_FONT`. Protected, and the splash's bottom-right tile: left transparent so both hold. |

The in-flight block `0xBF`-`0xC8` is a subset of the splash block, so it costs nothing: the same tiles draw the splash at boot and the wordmark in flight. No ASCII slot is sacrificed.

### Craft-name variant (Betaflight 4.4 and earlier)

The optional `*_craftname.mcm` builds copy the wordmark tiles onto typeable ASCII indexes, because the craft-name field cannot reach the splash range on those versions. **These glyphs are lost in that variant only**; the default builds leave them intact.

| Sacrificed index | Character | Receives tile |
|---|---|---|
| `0x21` | `!` | `0xBF` |
| `0x22` | `"` | `0xC0` |
| `0x23` | `#` | `0xC1` |
| `0x25` | `%` | `0xC2` |
| `0x26` | `&` | `0xC3` |
| `0x27` | `'` | `0xC4` |
| `0x28` | `(` | `0xC5` |
| `0x29` | `)` | `0xC6` |
| `0x2A` | `*` | `0xC7` |
| `0x3B` | `;` | `0xC8` |

Craft name to type in Configurator: `!"#%&'()*;`

| Category | Changed | Indexes |

| arrow | 16 | 0x60-0x6F |
